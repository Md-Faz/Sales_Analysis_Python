
# 🪔 Diwali Sales Analysis | Python Project

This is a beginner-friendly data analysis project focusing on Diwali Sales data. The goal of the analysis is to extract actionable business insights using Python (Pandas, Seaborn, Matplotlib) and help understand customer purchasing behavior during the festive season.

---

## 📌 Project Highlights

- **Data Cleaning**: Removed null values, corrected data types, handled categorical columns.
- **Exploratory Data Analysis (EDA)**: Used visualizations to uncover:
  - Top spending states
  - Most profitable product categories
  - Gender-wise spending behavior
  - Occupation-based purchasing trends
- **Visualizations**: Created using Matplotlib and Seaborn for better presentation.
- **Business Insights**: The analysis concludes with customer trends to inform marketing & sales decisions.

---

## 💻 Tools & Technologies

- Python
- Jupyter Notebook
- Pandas, Seaborn, Matplotlib
